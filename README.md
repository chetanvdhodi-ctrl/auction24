# Auction24 Fresh App

## Run locally
1. Install Node.js (LTS).
2. Open this folder in terminal.
3. Run `npm install`
4. Run `npm run dev`

## Deploy to Vercel
Upload this project to GitHub, then import the repository into Vercel.
Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Included
- Live auction dashboard
- Player queue
- Bid button
- Team selection
- Automatic purse deduction on SOLD
- SOLD / UNSOLD
- Player management view
- Team purse view
- Reset auction
- Responsive mobile UI

This is a starter frontend. Multi-device real-time bidding and permanent database storage require a backend/database integration.
